# История изменений

## 0.2.0

### Исправленные ошибки

- Экспорт KML для `Point`/`MultiPoint` больше не падает и не теряет координаты.
- Кнопка скачивания на вкладке НСПД больше не подменяет объект содержимым поля координат.
- Некорректный порядок координат и «мусор» в строках теперь дают понятную ошибку с номером строки.
- `Content-Disposition` с кириллицей формируется по RFC 5987 (корректное имя файла).
- Ошибки НСПД разделены на «не найдено» (404) и «сервис недоступен» (502); сырой ответ
  больше не уходит клиенту.
- Убраны неиспользуемые зависимости `fastkml` и `pygeoif`.
- Путь к `docs/index.html` больше не зависит от текущего каталога запуска.

### Улучшения

- Полная поддержка `MultiPolygon`, `MultiLineString`, `MultiPoint`, `GeometryCollection`.
- Явный выбор системы координат (`wgs84` / `epsg3857` / `auto`) и строгая валидация диапазонов.
- KML: `ExtendedData`, экранирование атрибутов, корректная упаковка KMZ.
- Клиент НСПД: ретраи с backoff, TTL-кэш, настраиваемый TLS, валидация кадастрового номера.
  Если сертификат НСПД не проходит проверку цепочки (российский УЦ), запрос автоматически
  повторяется без проверки TLS с предупреждением в логе; флаг `--insecure`/`NSPD_INSECURE_TLS`
  отключает проверку заранее.
- CLI с кодами возврата, площадью/периметром и сохранением исходного JSON.
- API: `POST /api/convert`, `GET /api/layers`, коды ошибок, GZip, security-заголовки.
- Веб-интерфейс: новый дизайн, drag & drop, импорт GeoJSON, DMS, добавление точек кликом,
  площадь/периметр, экспорт GeoJSON, копирование KML, тёмная тема, SRI и CSP.
- Тесты (ядро + API), линтер ruff, CI для Python 3.10–3.12 и проверка JS, Dockerfile.
